# アートスタイル別カラーパレット ＆ マテリアルプリセット

## 1. ローポリ・カジュアル（Low-Poly Casual / Vibrant Stylized）
- **トーン**: 明るく親しみやすい、おもちゃ箱のような温かみのある3Dスタイル。
- **パレット**:
  - Base: `#2d3748` (Slate Navy / 深みのあるスレート)
  - Sub: `#4a5568` (Muted Steel / 落ち着いた足場・壁)
  - Accent 1: `#38b2ac` (Mint Cyan / クリスタル・主要アイテム)
  - Accent 2: `#ecc94b` (Warm Amber / コイン・ポイント)
  - UI Foreground: `#f7fafc` (Off White)
- **シェーディング**: フラットシェーディング（`flat_shading = true`）、ソフトな環境光、程よいアンビエントオクルージョン。

---

## 2. ネオ・レトロ / サイバーファンタジー（Neo-Retro Cyber Fantasy）
- **トーン**: 暗い夜景やダンジョンに、洗練されたエミッション（発光）が映えるスタイル。
- **パレット**:
  - Base: `#0f172a` (Deep Midnight / 深い夜空)
  - Sub: `#1e293b` (Dark Slate / 金属や床)
  - Accent 1: `#06b6d4` (Pure Cyan / 魔法・エネルギー)
  - Accent 2: `#f43f5e` (Rose / 危険・HP・トラップ)
  - UI Foreground: `#e2e8f0` (Light Slate)
- **シェーディング**: トーンマップ（Filmic / ACES）、ブルーム（Glow）の適度な適用。

---

## 3. オーガニック / ナチュラル（Natural Earthy）
- **トーン**: 森林、草原、冒険を感じさせる自然系スタイル。
- **パレット**:
  - Base: `#2c3e2e` (Deep Forest)
  - Sub: `#8b5e3c` (Warm Wood / 土と木)
  - Accent 1: `#85d666` (Fresh Leaf / 新緑)
  - Accent 2: `#f59e0b` (Sunlight Gold)
  - UI Foreground: `#fef3c7` (Parchment White)
