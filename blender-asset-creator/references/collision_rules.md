# Blender → Godot コリジョン命名規則 ＆ インポート規約

## 1. 自動コリジョンサフィックス（接尾辞）

Blender内でオブジェクト名に以下のサフィックスを付与すると、Godot 4.x がインポート時に自動的に物理ノード（`StaticBody3D` / `CollisionShape3D`）を生成します。

| サフィックス | Godot変換後のノード構成 | 用途・推奨ケース |
| :--- | :--- | :--- |
| `-col` | メッシュ + `StaticBody3D` + `CollisionShape3D`（凹型コライダー） | 壁、地面、複雑な静的建造物 |
| `-convcol` | メッシュ + `StaticBody3D` + 凸型（Convex）コライダー | 樽、箱、岩、移動可能な障害物（軽量・高精度） |
| `-colonly` | メッシュ非表示 + `StaticBody3D` + `CollisionShape3D` のみ生成 | 不可視の当たり判定ボックス、透明な境界壁 |
| `-navmesh` | ナビゲーションメッシュノードに変換 | 敵AI・NPCの歩行可能エリア |

## 2. モデリング・トランスフォーム規範
1. **原点（Pivot Point）の位置**:
   - キャラクター、家具、宝箱、木などの地面に接地するアセットは、**必ずオブジェクトの底面（足元）を `(0, 0, 0)`** に設定してください。
2. **スケールと回転の適用**:
   - Blender内でサイズや向きを変更した場合、エクスポート/保存前に必ず `Ctrl + A` → `Apply All Transforms`（または `Apply Scale & Rotation`）を実行してください。
3. **マテリアル共有**:
   - 1つのオブジェクトに過剰なマテリアルを分属させず、可能であればカラーパレット用マテリアルを共有してドローコールを削減してください。
