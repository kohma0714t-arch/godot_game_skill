# 2Dキャラクター アニメーションステート制作規則仕様書

2Dゲーム（トップダウン／アクション）におけるキャラクターの動き（モーション）を生き生きと自然に見せるための、コマ割り・ポーズ設計ガイドラインです。

---

## 1. フルアクション7大ステートの設計仕様

### 1. Idle (待機モーション)
- **推奨コマ数**: 2〜4コマ (8 FPS)
- **再生方式**: ループ
- **演出の要点**:
  - 生きている感覚を与えるための胸部・肩・髪の穏やかな呼吸（1〜2pxの上下動 / Bobbing）。
  - 足元は完全に固定し、接地感をキープ。頭身比を崩さない。

### 2. Walk (歩行モーション)
- **推奨コマ数**: 4〜6コマ (10〜12 FPS)
- **再生方式**: ループ
- **演出の要点**:
  - コマ構成: `[右足踏み出し] -> [通過（最高点）] -> [左足踏み出し] -> [通過（最高点）]`
  - 踏み込み時に重心が1px下がり、通過時に1px上がる上下リズム。
  - 支え足が滑らないよう接地フレームを意識（フットスライディング防止）。

### 3. Dash (ダッシュモーション)
- **推奨コマ数**: 2〜4コマ (12〜15 FPS)
- **再生方式**: ループ
- **演出の要点**:
  - 前傾姿勢を強調し、通常歩行よりも頭部・重心の位置を低く設定。
  - 残像や足元の砂煙（スモーク）演出を付与。

### 4. Light Attack (弱攻撃 / 通常攻撃)
- **推奨コマ数**: 3〜4コマ (15 FPS)
- **再生方式**: ワンショット (One-shot)
- **演出の要点**:
  - `コマ1: 予備動作 (Windup)` - 短い振りかぶり（1フレーム）
  - `コマ2: 攻撃発生 (Slash/Hit)` - 軌跡エフェクトを伴う鋭い振り抜き
  - `コマ3: フォロースルー (Recovery)` - 残心の余韻（素早く待機へ復帰）

### 5. Heavy Attack (強攻撃 / スキル)
- **推奨コマ数**: 5〜6コマ (12 FPS)
- **再生方式**: ワンショット
- **演出の要点**:
  - 体重を乗せるため、しっかりとしたタメ（2フレーム）を入れる。
  - 振り下ろしフレームで地面への衝撃エフェクトや画面揺れ（スクリーンシェイク）を誘発する力強さ。

### 6. Hurt (被弾 / ダメージ)
- **推奨コマ数**: 2〜3コマ (12 FPS)
- **再生方式**: ワンショット
- **演出の要点**:
  - 攻撃を受けた方向とは逆へののけぞり姿勢。
  - 1フレーム目の白フラッシュ（無敵時間・被弾の視認性向上）。

### 7. Death (撃破 / 死亡)
- **推奨コマ数**: 4〜6コマ (10 FPS)
- **再生方式**: 終了時停止 (Clamp / Non-loop)
- **演出の要点**:
  - 力なく倒れ込むモーション、またはドット粒子となって消滅・霧散するエフェクト。
  - プレイヤーの達成感や切なさを演出。
