# トップダウン2Dタイル接続 & オートタイリング規則仕様書

トップダウン（見下ろし）視点の2Dゲームにおける壁・床・角タイルの接続整合性を保ち、見た目の崩れを防ぐための規格ガイドラインです。

---

## 1. トップダウン特有の壁構造（2段構成）

見下ろし視点の立体感を表現するため、壁は通常「壁の上面（Top）」と「壁の前面（Face）」の2段で構成されます：

```
[ Wall Top  ]  <- プレイヤーの頭上・天井に該当（通行不可）
[ Wall Face ]  <- プレイヤーと対面する壁の厚み面（コリジョン境界）
[ Floor     ]  <- 歩行可能な地面
```

### 接続ルール
1. **上壁の前面落ち**:
   - 壁の上面タイルの直下には、必ず壁前面（Face）タイルを配置する。
2. **影レイヤー（Drop Shadow）**:
   - 壁の前面から床への境界には、1〜2pxまたは半マス分のドロップシャドウを落とすことで奥行きを強調。

---

## 2. 角タイル（コーナー）の整合ルール

| コーナー種別 | 判定条件 | 期待されるタイル |
| :--- | :--- | :--- |
| **外角（Outer Corner）** | 壁の端で90度曲がる箇所 | L字型外角タイル（丸みまたは切り欠き） |
| **内角（Inner Corner）** | 部屋の角で壁と壁が合流する凹み箇所 | 内角用の影付き結合タイル |
| **T字路・十字路** | 通路の合流地点 | 3方向/4方向接続用ジャンクションタイル |

---

## 3. テストにおけるNGパターンと改善策

1. **孤立した1マス壁（Isolated Wall）**:
   - 柱としての装飾でない限り、タイリングの欠落であるため周囲と連結するか床に置き換える。
2. **壁に囲まれた1マスの穴（Hole in Wall）**:
   - プレイヤーが侵入不能かつ視覚的にも不自然なため、壁で埋める。
3. **壁内部へのオブジェクト埋没**:
   - 松明や樽が壁のコリジョン内部に配置されている場合は、床側のマスへオフセット移動する。
